# 八卦万物类象

## 一、八卦基本象征

### 乾卦（天）
- **象征**：天、君、父、首领、刚健
- **方位**：西北
- **五行**：金
- **身体**：头、骨、肺
- **人物**：领导、长辈、名人
- **事物**：金玉、珠宝、圆形物
- **性格**：刚健、果断、有权威

### 坤卦（地）
- **象征**：地、母、众、柔顺
- **方位**：西南
- **五行**：土
- **身体**：腹部、脾胃、肌肉
- **人物**：母亲、大众、普通人
- **事物**：田野、布帛、方形物
- **性格**：柔顺、包容、厚德载物

### 震卦（雷）
- **象征**：雷、动、长男、起动
- **方位**：东
- **五行**：木
- **身体**：足、肝、头发
- **人物**：长男、军人、运动员
- **事物**：车辆、乐器、竹木
- **性格**：积极、有行动力、急躁

### 巽卦（风）
- **象征**：风、入、长女、柔和
- **方位**：东南
- **五行**：木
- **身体**：大腿、胆、呼吸系统
- **人物**：长女、商人、僧道
- **事物**：绳索、工巧、帆船
- **性格**：柔和、灵活、善变

### 坎卦（水）
- **象征**：水、险、中男、智慧
- **方位**：北
- **五行**：水
- **身体**：耳朵、肾、血液
- **人物**：中男、江湖人士、谋士
- **事物**：沟渠、酒水、隐伏物
- **性格**：聪明、多谋、阴险

### 离卦（火）
- **象征**：火、明、中女、文化
- **方位**：南
- **五行**：火
- **身体**：眼睛、心脏、小肠
- **人物**：中女、文人、艺术家
- **事物**：文书、灯火、甲胄
- **性格**：光明、热情、急躁

### 艮卦（山）
- **象征**：山、止、少男、守静
- **方位**：东北
- **五行**：土
- **身体**：手指、背部、鼻子
- **人物**：少男、山中人、守卫
- **事物**：门阙、小路、岩石
- **性格**：稳重、固执、守静

### 兑卦（泽）
- **象征**：泽、悦、少女、口舌
- **方位**：西
- **五行**：金
- **身体**：口、肺、牙齿
- **人物**：少女、歌手、翻译
- **事物**：沼泽、乐器、废物
- **性格**：喜悦、善言、口才好

## 二、八卦在占卜中的应用

### 上卦（外卦）代表
- 外界环境
- 对方
- 事情的表面现象
- 未来的发展方向

### 下卦（内卦）代表
- 内心想法
- 自己
- 事情的本质
- 过去的原因

### 卦象组合解读
- 两个单卦的五行关系决定体用生克
- 上下卦的象征含义相互结合
- 动爻所在卦为用卦，不动之卦为体卦
